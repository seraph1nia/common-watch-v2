# Menu background

`main_menu_background.png` is an unchanged copy of the user-supplied
`From Enchanted Forest to Burning Wasteland.png` (1672 × 941).
SHA-256: `0f015721cd6626aed2a9b33886c482d57863b0aa9353654e9c7a85f30eefd817`.

All menu screens fit the entire static image inside the viewport, preserving its
aspect ratio and the peaceful forest, central battle and dark wasteland. It is
shown in both plain and illustrated modes for the main menu, multiplayer/LAN and
Steam entry points, solo/network doctrine chooser and settings. Settings has its
own backdrop behind its existing modal panel, including when opened from a match.
Gameplay and its existing world-backed dialogs retain their presentation. A
missing image retains the plain menu and the original settings shade.

The application owns the texture and loads it from this project directory,
beside `assets/sprites`. Release builds already copy the complete `assets`
directory, so no runtime path refers to Downloads.
