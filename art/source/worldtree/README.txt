Common Watch Worldtree UI Pack
==============================

Contents
- assets/worldtree_background.png
  Full 16:9 static worldtree / skilltree background image with 18 empty node sockets.
- assets/worldtree_node_idle.png
  Transparent circular node ring for normal/idle state.
- assets/worldtree_node_hover.png
  Transparent circular node ring for hover/available state.
- assets/worldtree_node_selected.png
  Transparent circular node ring for selected/focused state.
- assets/worldtree_node_owned.png
  Transparent circular node ring for acquired/owned state.
- assets/worldtree_node_locked.png
  Transparent circular node ring for locked/unavailable state.
- assets/worldtree_details_panel.png
  Transparent decorative panel frame for the node details/info area.

Suggested usage
- Use the background as a static scene inside the Worldtree/Skilltree screen.
- Place 18 interactive controls over the painted node sockets.
- Render technology icons centered inside the node rings.
- Swap ring textures based on node state (locked, available, hovered, selected, owned).
- Use the details panel in the lower-right open space or as a floating anchored panel.

Notes
- Measure actual socket positions from the background image during implementation rather than guessing.
- The pack does not contain gameplay icons; reuse existing technology icons if available, or use current placeholders.
- The pack is presentation-only and is intended to preserve the existing rules and Worldtree logic.
